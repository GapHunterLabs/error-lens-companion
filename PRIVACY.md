# Privacy Policy — Error Lens Companion

**Effective date:** 2026-08-14

Error Lens Companion is a Gap Hunter Labs plugin for IntelliJ Platform
IDEs. This policy is short because the plugin's design makes it short:
there is nothing to disclose beyond what's below.

## What this plugin collects

**Nothing.** Error Lens Companion does not collect, store, transmit, or
sell any data — no source code, no file contents, no usage analytics,
no telemetry, no crash reports, no personally identifiable information.
It only reads diagnostic text (error/warning messages) the IDE's own
highlighting already computed, and only to render it back inline in
your own editor.

## Network access

**None.** Error Lens Companion makes zero network calls during normal
operation. Everything runs entirely in-process, inside your IDE.

## Third parties

None. Error Lens Companion has no third-party SDKs, no analytics
libraries, no ad networks, no external dependencies that phone home.

## Changes to this policy

If this ever changes, this file will be updated and the change will be
noted in the plugin's `CHANGELOG.md`.
